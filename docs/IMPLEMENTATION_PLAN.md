## Implementation increments

These increments subdivide the eight phases in the latest specification; service extraction alone does not complete specification Phase 2, which also requires Kafka and Redis.

2. **Service architecture:** implemented and verified natively and in Docker Compose, including resumable workflows and recovery.
3. **Kafka/Redis:** purchase outbox, real Kafka publication/consumption, manual consumer-group offsets, retries and database quarantine implemented and verified. Redis caching and shared purchase limits are verified natively and in Compose. Payment-state and notification-delivery events now use service-owned transactional outboxes and are verified through Kafka. Broker lag metrics are verified in the observability increment; reviewed operator reprocessing is verified in the later dead-letter increment.
4. **Observability foundation:** OTel HTTP/database/Kafka spans, Prometheus counters/histograms, Grafana dashboards and alerts, structured correlated logs.
5. **ITOC UI:** full health, incidents, deployments, operational KPIs and SLO/error budget views.
6. **Incident system:** all eight lifecycle states, timestamps, ownership, escalation, aligned evidence, structured RCA, postmortem and action items.
7. **Enterprise observability:** meaningful Splunk and Dynatrace adapters/configuration, SPL queries and contextual deep links. Credentialed vendor ingestion must be explicitly verified or reported unverified.
8. **Failure simulation:** deterministic application/database/dependency/business failures, Kafka lag, resource exhaustion and bad deployment/rollback. Complete recovery validation.
9. **Kubernetes:** deployments/services/config/secrets/ingress, probes, requests/limits, autoscaling/disruption policies and reproducible failure scenarios.
10. **OpenShift:** arbitrary-UID-compatible images, portable security context and environment-specific Helm values.
11. **CI/CD:** GitLab lint/typecheck/tests, SonarQube quality gate, image/security checks, JFrog-compatible artifacts, Jenkins promotion/rollback, smoke/k6 checks.
12. **Security:** auth-service, SSO-ready secure sessions, authoritative RBAC for all five roles, CSRF/rate limits, audit history and documented corporate/public boundary.
13. **Enterprise UX:** saved views, advanced table controls, global search, notification center, profile/roles, partial/error/permission states and accessibility checks.
